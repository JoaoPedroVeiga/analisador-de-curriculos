## 📖 Versão Longa (para artigo ou README profissional)

### Projeto: Analisador de Currículos com Inteligência Artificial

#### Visão Geral

Desenvolvimento completo de uma aplicação fullstack que automatiza a análise de currículos utilizando Inteligência Artificial. A solução processa arquivos PDF, extrai informações estruturadas e gera insights profissionais detalhados em segundos, substituindo análises manuais demoradas por um processo automatizado e preciso.

#### Desafio e Solução

O processo tradicional de análise de currículos apresenta limitações significativas: é subjetivo, consome muito tempo e pode deixar passar informações importantes. Este projeto resolve essas questões através de:

1. **Automação Completa:** Upload de PDF → Extração → Análise IA → Resultados formatados
2. **Análise Multidimensional:** Avaliação em 4 eixos principais (técnico, experiência, comunicação, geral)
3. **Insights Estruturados:** Dados organizados em JSON para fácil processamento e visualização
4. **Precisão com IA:** Utilização de modelos de linguagem avançados para compreensão contextual

#### Arquitetura do Sistema

**Camada de Apresentação (Frontend)**
• Next.js 15 com App Router e React Server Components
• React 19 com hooks modernos e estado local
• TailwindCSS 4 para estilização utility-first
• Framer Motion para animações e transições
• react-dropzone para upload com drag-and-drop
• Design responsivo e acessível

**Camada de Negócio (Backend)**
• NestJS com arquitetura modular e injeção de dependências
• TypeScript para type safety em toda a aplicação
• Prisma ORM para abstração de banco de dados
• PostgreSQL como banco de dados relacional
• Integração com OpenAI API para análise de texto
• pdfjs-dist para extração robusta de texto de PDFs

**Processamento de Dados**
• Extração de texto página por página de arquivos PDF
• Tratamento de erros para PDFs protegidos ou corrompidos
• Limitação e otimização de texto para APIs de IA
• Validação e parsing de respostas JSON estruturadas

**Análise com IA**
• Prompt engineering avançado para análise contextual
• Especificação de formato JSON para respostas estruturadas
• Temperatura baixa (0.1) para consistência máxima
• Análise em português brasileiro com contexto de mercado local

#### Sistema de Pontuação

O sistema avalia currículos em múltiplas dimensões:

**Score Técnico (0-100)**
• Mapeamento completo da stack tecnológica
• Avaliação de profundidade técnica por tecnologia
• Identificação de conhecimentos modernos vs. desatualizados
• Análise de evolução tecnológica na carreira

**Score de Experiência (0-100)**
• Análise quantitativa de resultados e conquistas
• Progressão de carreira e saltos profissionais
• Relevância de empresas e setores
• Medição de impacto real nas organizações

**Score de Comunicação (0-100)**
• Clareza na descrição de experiências
• Objetividade e poder de síntese
• Estrutura lógica e hierarquia de informações
• Adaptação a sistemas ATS (Applicant Tracking Systems)

**Score Geral**
• Média ponderada: Técnico (40%) + Experiência (35%) + Comunicação (25%)
• Representa a avaliação holística do perfil profissional

#### Estrutura de Dados Retornados

A IA gera uma análise completa estruturada:

```json
{
  "summary": "Resumo profissional objetivo (150-200 palavras)",
  "strengths": ["Ponto forte específico 1", "Ponto forte 2", ...],
  "improvements": ["Sugestão de melhoria 1", "Sugestão 2", ...],
  "score": {
    "technical": 0-100,
    "communication": 0-100,
    "experience": 0-100,
    "overall": 0-100
  },
  "technical_skills": {
    "programming_languages": [...],
    "frameworks_libraries": [...],
    "tools_platforms": [...],
    "databases": [...],
    "cloud_services": [...],
    "methodologies": [...]
  },
  "career_analysis": {
    "level_identification": "Junior/Mid-Level/Senior/Specialist",
    "market_position": "Posicionamento atual",
    "growth_trajectory": "Análise de progressão",
    "recommended_roles": ["Cargos recomendados"]
  }
}
```

#### Fluxo de Funcionamento

1. **Upload:** Usuário faz upload de PDF através de interface drag-and-drop
2. **Extração:** Backend processa PDF e extrai texto de todas as páginas
3. **Validação:** Sistema verifica qualidade e integridade do texto extraído
4. **Análise IA:** Texto é enviado para OpenAI com prompt estruturado
5. **Processamento:** IA retorna análise completa em formato JSON
6. **Validação:** Sistema valida estrutura e campos obrigatórios
7. **Persistência:** Dados são salvos no PostgreSQL via Prisma
8. **Apresentação:** Frontend exibe resultados com animações e formatação

#### Funcionalidades Técnicas Implementadas

**Backend:**
• API RESTful com endpoints `/resume/upload` e `/resume/:id`
• Extração de texto de PDFs multi-página
• Integração robusta com OpenAI API
• Validação de arquivos e tratamento de erros
• Sistema de scoring com pesos configuráveis
• Persistência de análises para histórico

• Animações de transição entre estados
• Cards de pontuação com cores dinâmicas
• Layout responsivo para mobile e desktop

#### Desafios e Soluções

**Desafio 1: Extração de Texto de PDFs**
• Problema: PDFs podem ter diferentes estruturas e formatações
• Solução: Implementação de pdfjs-dist com tratamento robusto de erros e validação de texto extraído

**Desafio 2: Limitação de Tokens da API**
• Problema: Currículos longos excedem limites de tokens
• Solução: Limitação inteligente de texto mantendo contexto relevante (12.000 caracteres)

**Desafio 3: Respostas Estruturadas da IA**
• Problema: Garantir formato JSON válido e consistente
• Solução: Prompt engineering detalhado + `response_format: { type: 'json_object' }` + validação de campos obrigatórios

**Desafio 4: UX Durante Processamento**
• Problema: Processamento demora alguns segundos
• Solução: Estados de loading com progresso visual e mensagens informativas em cada etapa
